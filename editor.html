Simple Touch manual designer

Name every control, mark pads or knobs as modifiers and get a manual that lays its labels out by itself: boxes on the controls for phones, side columns with leader lines for desktop. Start from a reference label set or an official firmware. Everything is kept in this browser.

Open repository

Reads simple-touch-labels.json from the root of the default branch. Without it, a script fills in the labels from the README and a manual it links to. The repository does not have to be in the community directory.
Community directory entry

The Synthux community directory lists firmware for Synthux instruments, one small JSON file per project. This one is built from the Labels tab: name, author, repository and author link.


    

  




  

    
Repository kit

    
Everything for your firmware's repository in one .zip: a README with the control map, your label file and the community directory entry. The install and build steps are suggestions; check them and fill in what is marked TODO. HOW-TO.txt in the .zip says where each file goes. Commit them to your default branch (usually main): the library reads nothing else. How this works
